# 「刻む」タブ 作業記録

MIXタブを「刻む」タブ（原曲を刻んで、新しい曲を作る場所）に作り直してから、いまの形になるまでに何をしたかの記録。
細かい仕様は SPEC.md の 4.5、日々の進み具合は PROGRESS.md にある。ここは「流れ」と「なぜそうしたか」をまとめる。

## 決まっていること（ユーザーの指定）

- **フレーズ＝1つの曲**。刻むときは、フレーズを1本の波形（WAV相当）に書き出して、その波形を刻む。中の層（ドラム・ベースなど）には分けない（例外：ドラムループだけは、ドラムの層だけを別に書き出す。ユーザーの提案）。
- **刻んだ曲のBPMは、フレーズのBPMと無関係**。フレーズは曲のBPMで書き出し直す。
- **セクション（イントロ・Aなど）・盛り上がりの山は持たない**。
- 刻むタブでは下の鍵盤を出さない。スペースは再生⇔停止。
- 質感の名前は、参考にした解説動画の言葉（満・刻・細）をそのまま使わず、**なめらか／キレ／ちりばめ**にする。
- パンの最大はいまのまま。
- 画面は **DAW っぽく**、エフェクトは **REAPER と同じ考え方**で。専門的でもいい。
- 曲の長さは、テンポに関係なくどれでも選べる（30秒未満を禁止していたのは取りやめ）。
- **ミュートは「このトラックを抜いたら、同じ曲がどう聞こえるか」を聞く道具**。ミュートしても、ほかのトラックの打つ内容は変えない（番を回し直さない）。
- リバーブの**音は変えない**（速くするのはいいが、音が変わる方法は取らない）。
- 作りは **DAW のミキサーの考え方**（トラックごとに鳴らして、フェーダーで足す）。「DAW として作る」が目標。

## いまの作り（ファイル）

- 音を作る（`src/mix/`）
  - `collageSong.ts`：全体の組み立て。`buildStems`（トラックごとに書き出し→切る→打つ→グループ・テイクFX・トラックFX→サイドチェイン、パッドは曲ごと、ドラムループ、効果音＝**ステム**）→ `mixdown`（フェーダー〔音量・ミュート・ソロ・定位・マスター〕を掛けて足す → マスターFX → コンプ・リミッター）。`buildCollage` は両方をつなげた入口。`songFaders` がフェーダーの値を決める。
  - `masterBusStream.ts`：マスターのコンプ・リミッター（ストリーム処理。何も import しない）。`masterBus.ts` は曲全体を流す書き出し用（`masterBusLoop` は曲の頭を終わりからの続きとして処理）。
  - `buildCache.ts`：変わっていないトラックの波形の使い回し。
  - `musicChop.ts`：音楽モード。`sequencer.ts`／`slicer.ts`：素材モード。
  - `collage.ts`：断片を打って1本の波形にする（音程・パン・長さ・強さ・フィルの加工・スウィング）。
  - `glue.ts`：効果音・パッド・サイドチェイン。
  - `fx.ts`：REAPER 風のエフェクト（FXチェーン・エンベロープ・テイクFX、前の形の読み込み）。
  - `groups.ts`：グループ。
  - `types.ts`：曲のデータと読み込み（古い形からの変換）。
- 画面（`src/ui/`）
  - `mixPanel.ts`：刻むタブ全体（トランスポート・アレンジ画面・インスペクタ）。
  - `laneView.ts`：トラックの線（断片・エンベロープ・四角で選ぶ）。
  - `fxWindow.ts`：FXチェーンの窓。
  - `mixWidgets.ts`：つまみ・選択・開け閉めできる見出し。
- 書き出し・再生（`src/audio/`）：`renderPhrase.ts`（フレーズ→波形。ドラムだけ・スウィングも）、`reverbWet.ts`（リバーブの響きだけ。曲を分けて同時に処理）、`stemMixer.ts`（再生側のミキサー：ステムごとにループ再生 → フェーダー・定位 → 足す → リバーブ → マスター → マスターのフェーダー。`buildMixerGraph` は `OfflineAudioContext` にも使える）、`masterBusWorklet.ts`（マスターのコンプ・リミッターの `AudioWorklet`）。マスターのFXがリバーブだけ（デフォルト）でないとき・`AudioWorklet` が使えないときは、ミックスダウンした波形を `loopPlayer.ts` で鳴らす（ミュートなどは作り直し）。

## 点検して直したこと（PR #37 のあと）

サブエージェント3つ（音の処理・画面・保存）で点検し、確かめられたものを直した。

- **保存**：起動直後に曲がフレーズ一覧より先に読まれると、空の一覧で素材・トラックが消され、次の保存で失われていた／別のアカウントに切り替えると前の人の曲を保存していた／タブを閉じる直前の変更を落としていた／素材を外してまた選ぶとトラックの設定が消えていた／消したフレーズの断片がグループに残っていた／ドラムループの曲を消すと「なし」になっていた。
- **画面**：チェックボックスやスライダーを触ったあとのスペースで素材が外れていた／タッチで四角選びのあと次のタップが効かなかった／相手が消えてもFXの窓が開いたままだった／エンベロープで既存の点の上下に点を足すと前の点が動いた／スマホで線の上からスクロールできなかった／グループ名を変えても表示が古いままだった。
- **音**：テイクFX・グループFXがあると、断片ごとに曲全体の長さを作っていてとても重かった（64小節・40BPMで37〜56秒 → 約6秒）／ハイパス・ローパスがくり返しのつなぎ目でプチッとしていた／交代で、短い曲だと3つ目以降のトラックが鳴らなかった／エンベロープの計算が点の数に比例して重かった／テイクFXの位置が小数で保存されていると片方が消えていた。

## まだのこと・気になっていること

- スウィングは、断片を打つ位置にだけ掛かる。1拍以上の長い断片の中身（元の16分）はまっすぐのままなので、強いスウィングとドラムループを合わせると、ずれて聞こえることがある。

- **耳での確認がまだ**。数字（無音の割合・左右の相関・プチ音の有無）でしか確かめていない。
- テイクFX・グループは断片を「位置」で覚えるので、刻み直してその位置に断片が無くなると効かない。
- エンベロープで動かせるのは「量」と「ウェット」だけ（リバーブの長さ・ディレイの間隔は動かせない）。
- グループで変えられるのは、断片1つ1つの性質（音程・パン・長さ・強さ・逆再生・ミュート・FX）だけ。「そこだけ刻み直す（密度やリズムを変える）」はまだ。
- 同じフレーズを2本のトラックとして並べることはできない（トラックはフレーズのidで見分けている）。
- Safari 実機での確認がまだ（特に `AudioWorklet` とメモリ。ステムは30秒・3トラックで再生用のコピーと合わせて約170MB）。
- ミキサーでできないこと：センド／リターン式のリバーブ、フェーダーのオートメーション、ミキサー操作のやり直し。
